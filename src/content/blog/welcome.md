# Welcome! 🚀

I'm excited to launch my new blog powered by **Jekyll** and the beautiful **Chirpy** theme. This is where I'll be sharing my journey through web development, creative projects, and all the interesting things I'm learning along the way.

## Why Jekyll?

I decided to switch from my Laravel blog to Jekyll because:

- **Markdown-focused** - Pure content with git version control
- **Fast & lightweight** - No database needed, just static files
- **Dark mode** - Built-in theme switcher with light/dark options
- **Perfect for blogging** - Minimal distractions, content-first approach
- **Easy deployment** - Netlify handles everything automatically

## What to expect

This blog will feature:

* Technical posts about web development
* Project updates and case studies
* Learning notes and tutorials
* Creative explorations and experiments

Check out the theme toggle in the top right! The color scheme is customized with my favorite purple gradients.
